## 🚀 快速开始

### 在线使用

直接访问 **[OpenBox 网站](https://weed33834.github.io/OpenBox/)** 即可浏览所有站点，支持：
- 🏠 **海报入口** → 分类磁贴 → 子分类 → 站点列表，多级导航
- 🔍 **按分类/类型/状态筛选**，关键词与模型搜索
- ❤️ **实时健康检测** — 前端直连检测站点可用性
- 📊 **站点对比** — 选中多个站点进行横向对比
- ⭐ **收藏管理** — 收藏常用站点，支持导出为 JSON
- 🌐 **多语言** — 中文 / English / 日本語
- 📱 **响应式设计** — 桌面端网格布局，移动端底部导航+手势交互
- 🎨 **页面转场动画** — 前进/后退方向感知的滑动切换

### 本地开发

```bash
git clone https://github.com/weed33834/OpenBox.git
cd OpenBox
npm install --legacy-peer-deps
npm run dev
```

### 构建部署

```bash
npm run build
# 产物在 dist/ 目录，自动部署到 GitHub Pages
```

## ✅ 功能特性

- **站点浏览** — 按分类/类型/状态筛选，关键词与模型搜索
- **实时健康检测** — 前端直连检测站点可用性，状态一目了然
- **站点对比** — 选中多个站点进行横向对比（支持桌面表格/移动端卡片）
- **收藏管理** — 收藏常用站点，支持导出为 JSON
- **多语言** — 中文 / English / 日本語
- **响应式设计** — 桌面端网格布局，移动端底部导航交互
- **深色/亮色主题** — 赛博风格暗色主题，支持一键切换
- **页面转场动画** — 前进/后退方向感知的滑动切换
- **移动端手势** — 右滑返回上一页
- **全局搜索** — 搜索站点名称、模型、描述等
- **详情抽屉** — 点击卡片展开详情，包含站点信息、优缺点、使用建议
- **站点举报** — 发现失效站点可一键举报
